# Живое ревью интерфейса (сборка 6b45ed4, Windows 11, 2026-11-18)

По снимкам установленной программы: вкладки Друзья, «Друг прислал мне текст», Добавить друга, Отправить, Входящие, Настройки (нижняя часть). Не смотрели: Передачи, Диагностика, Обновления, верх Настроек, сверка кода, передача файла.

## Высокий
- **Ж1. Стрелка «→» показывается квадратиком.** В шрифте окна нет этого знака. 18 текстов (gui/texts.rs 10, connect/texts.rs 6, core/node/texts.rs 2): каждый совет «вкладка → кнопка» выглядит сломанным. Регрессия 18б. Заменить на « › » или «, затем», и добавить тест: все символы текстов есть в шрифте окна.
- **Ж2. «Ваш адрес в интернете изменился…» висит над каждой вкладкой при пустом списке друзей.** Совет «у каждого друга…» невыполним, друзей нет. Не показывать без друзей. Общие уведомления занимают верх всех вкладок (С2).
- **Ж3. «Добавить друга»: две оранжевые строки ещё до нажатия кнопки.** Первая — предупреждение про адрес (Н3), вторая — «Нет адреса… укажите адрес с пробросом порта». Кнопка «Создать приглашение» при этом активна, хотя заранее известно, что не сработает. Поле «Свой адрес с пробросом порта, IP:порт» — жаргон (В4, В5, П6). Закрывает 13д; до него — хотя бы не показывать предупреждение до создания и объяснить, что делать, по-человечески.
- **Ж4. «Пересоздать все ключи» стоит второй кнопкой на «Друзьях» рядом с главной, при нуле друзей.** Разрушительное действие на главном экране (С11 не сделан). Оставить только в «Настройки → Ключи».

- **Ж20. «Диагностика» → «Ваша сеть» при нуле друзей пишет «Друг не отвечает: возможно, он выключил программу…».** Под заголовком о своей сети — текст про друга, которого нет. Ошибка выбора текста (состояние сети «неизвестно» сопоставлено с текстом про друга). Кнопка «Попросить роутер открыть порт **ещё раз**», хотя роутер ни разу не открывал (в Настройках «Разрешённых роутеров нет»). Нужно: при нуле друзей — «Сеть проверится, когда появится первый друг»; кнопка без «ещё раз», пока порт не открывался.

## Средний
- **Ж21. «Обновления»: раздел «Проверить скачанные файлы» (chervo-release.txt, .minisig, «откат», «Вшитые ключи владельца (сверьте с README)»)** — инструмент для опытных на виду у всех. Свернуть под «Для опытных: проверить скачанный установщик». «Ключи владельца не вшиты» в выпуске быть не должно (в пробной сборке ожидаемо).
- **Ж22. «Обновления» отдельной вкладкой** при одном флажке и одной кнопке — перенести в Настройки (см. Ж11).
- **Ж5. Окно «Друг прислал мне текст» перечисляет коды «CHV1», «CHA1».** Человеку они не нужны: «Вставьте текст, который прислал друг» достаточно, программа разберётся сама. Поле ввода почти чёрное на тёмном фоне, без подсказки внутри; на снимке не видно кнопки «Применить» рядом с «Отмена» (проверить при узком окне).
- **Ж6. «Отправить»: кнопка «Отправить» активна без файлов и без друзей.** Делать неактивной с причиной; «Нет друзей, которым можно отправить» дополнить кнопкой «Добавить друга».
- **Ж7. Настройки, локальная сеть: «Ищем на адресах: 172.18.0.1, 192.168.31.246, 192.168.240.1».** В списке адрес туннеля sing-box и WSL: поиск идёт и по виртуальным сетям. Сами адреса человеку не нужны (и это IP на экране). Показывать «Ищем друзей в домашней сети» и, если найден VPN, одну фразу про него.
- **Ж8. Настройки, роутер: «Возможно, в его настройках выключен UPnP».** Жаргон без шага: что сделать человеку. Сюда же помощник 13д.
- **Ж9. Настройки, часы: «Текущая поправка: 2953 мс», список из девяти серверов времени.** Технические подробности на виду. Свернуть под «Подробнее»; на виду — «Часы сверены» / кнопка.
- **Ж10. «Режим „локальные ключи“ в этой версии недоступен.»** (Н8) — убрать.

- **Ж15. Папка приёма: пустое поле + «Выбрать…» + отдельная «Сменить папку».** Два шага и пустое поле при уже заданной папке «Сейчас: Z:\worm_files». Поле должно показывать текущую папку; «Выбрать…» сразу меняет её (с вопросом «Сменить?»), вторая кнопка не нужна.
- **Ж16. Три кнопки «Сохранить» подряд** (запас места, порт, внешний порт). Одна кнопка на раздел или сохранение по выходу из поля. «% тома» → «% диска».
- **Ж17. «Если вы сами открыли порт на роутере, укажите его номер»** — для обычного человека непонятно, откуда номер; заменяется помощником 13д («Открыть доступ из интернета»).
- **Ж18. Локальная сеть: три длинных абзаца у переключателя**, под ним ещё «Слушаем локальную сеть» и адреса. Коротко на виду («Не искать», «Искать», «Искать и сообщать о себе — только дома»), подробности под «Подробнее».

## Низкий
- **Ж19. «Хранилище ключей: Диспетчер учётных данных Windows»** — техническая строка, можно под «Подробнее».
- **Ж11. Восемь вкладок, «Обновления» отдельной вкладкой** (Н10). Обновления — в Настройки.
- **Ж12. Пустые экраны** («Входящих предложений нет.») не говорят, что здесь появится и откуда; одна строка «Здесь появятся файлы, которые вам предложит друг».
- **Ж13. Серый мелкий текст на тёмном фоне** у подсказок — низкий контраст.
- **Ж14. Пустое состояние «Друзей пока нет…»** — дать сразу кнопку «Пригласить друга», а не текст с путём.
