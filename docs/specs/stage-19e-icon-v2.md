# Этап 19е: значок, версия 2 («мост со спиралью и файлом»)

Обычный этап (не критичный), исполнитель builder. Заменяет рисунок в `packaging/icons/make-icons.py` (Q2 в `OWNER_DECISIONS.md`: прежний значок был временным). Остальное в скрипте не трогать: формат вывода, `--out`, `--check`, `--self-test`, ICO/ICNS/RGBA, имена файлов, коды возврата, ограничения Р19е-10 из `stage-19e-installers.md`. Рисунок утверждён владельцем по эскизам 2026-11-16.

## 1. Жёсткие ограничения (Р19е-10, не менять)
- Только стандартная библиотека; математика только `+ - * /` и `math.sqrt`. **Без `math.sin/cos/atan2/exp/pow` с нецелой степенью.** Для спирали нужны cos/sin: считать без тригонометрии. Варианты: поворот на фиксированный шаг рекуррентно (cos/sin шага получить рядом Тейлора, только `+ - * /`), либо иной детерминированный способ. Результат обязан совпадать побайтно по пикселям на Linux, Windows и macOS (CPython, IEEE 754 double).
- Степень `d^1.8` (ниже) нельзя считать через `**1.8`. Заменить её детерминированной функцией близкой формы, например `d*d*(a+b*d)` с подобранными `a`, `b` или кусочно-полиномиальной, и записать формулу в комментарии.
- Время `--out` для всех размеров на обычной машине до ~60 с. Если выходит дольше, доложить, не жертвовать детерминизмом.

## 2. Геометрия (в координатах холста 100×100, ось y вниз; масштаб под размер)
- Фон: скруглённый квадрат на весь холст, радиус 22, цвет `#1b1b1f`; вне него прозрачно (сглаженный край).
- Контур моста (две кривые Безье 3-го порядка): левая `P0(20,24) P1(44,38) P2(44,66) P3(20,80)`, правая симметрична (x → 100−x). `yc(t)` и `xL(t)` — координаты левой кривой при параметре t∈[0,1]; полуось кольца `rx(t)=50−xL(t)`, `ry(t)=rx(t)*8/30`.
- Цвет вдоль моста: линейно от `#4fa3ff` (t=0, вход сверху) к `#8e7cff` (t=1, выход снизу).
- Вход: эллипс `cx50 cy24 rx30 ry8`. Выход: эллипс `cx50 cy80 rx30 ry8`. Толщина линии входа и выхода 2.
- Файл (лист), повёрнут на −10° вокруг (50,18): многоугольник `(39,3) (53,3) (61,11) (61,31) (39,31)` цвет `#e8e8ec`; загиб `(53,3) (53,11) (61,11)` цвет `#a9a9b6`; на размерах ≥128 две строки: отрезки `(43,17)–(57,17)` и `(43,22)–(57,22)`, толщина 2, цвет `#8e8e9c`. Поворот на −10° — постоянные cos/sin, задать числами в коде (например 0.984807753012208, −0.17364817766693033).

## 3. Тело моста по размерам
| Размер | Тело |
|---|---|
| 512 | спираль, N=30 витков |
| 128, 256 | спираль, N=25 витков |
| 48, 64 | спираль по той же формуле, 48 → N=8, 64 → N=10 (правка владельца: вместо трёх колец); лист без строк |
| 16, 32 | без колец и спирали: только контур моста — две кривые Безье толщиной 4 (левая цвета входа, правая цвета выхода), вход и выход толщиной 4; лист без строк |

Спираль (размеры 128–512): точка `(50+rx(t)·cos θ, yc(t)+ry(t)·sin θ)`, `θ=2π·N·t`, t от 0 до 1. Видимая (передняя) часть — где `sin θ ≥ 0`, полная непрозрачность; задняя — `sin θ < 0`, непрозрачность 0.28. Толщина линии (в единицах холста 100): `w(t)=mn+(2−mn)·g(d)`, `d=|2t−1|`, `mn=0.6·18/N` (N=30 → 0.36; N=25 → 0.432), `g(d)≈d^1.8` (см. разд. 1). Концы линии круглые.

## 4. Порядок слоёв (снизу вверх)
фон → задняя часть спирали (или кольца на 48/64; контур на 16/32) → выход → задняя половина входа (верхняя дуга эллипса, y ≤ 24) → лист → передняя часть спирали → передняя половина входа (нижняя дуга, y ≥ 24).
Смысл: передний край входа и передние витки проходят поверх низа листа, лист «уходит» в воронку.
