# Промпт для запуска облачной сессии

Запускать облачную сессию Claude Code на репозитории `rekc2004/chervotochina` (ветка `main`) и вставить текст ниже целиком.

```
Ты работаешь в репозитории chervotochina (проект «Червоточина»: прямая передача файлов между компьютерами без посредников, в российском сегменте интернета без VPN). Владельца нет на связи, переспросить нельзя.

Порядок, строго по шагам, результат каждого читай до следующего:
1. Прочитай целиком: docs/BRIEF.md, docs/TASK.md, .claude/combine/CORE.md, .claude/combine/pipeline.md. Не нарушай ограничения из BRIEF.md, раздел 2.
2. Выполни этапы 2, 3, 4, 5 из docs/TASK.md по порядку. Режим запуска без владельца, лимиты, остановка после этапа 5 и состав отчёта docs/REPORT-1.md описаны в docs/TASK.md. Следуй им буквально.
3. Роли и модели берутся из агентов combine-scout, combine-skeleton, combine-builder, combine-architect, combine-security (файлы .claude/agents/). Поиск и чтение отдавай combine-scout, проектирование и выводы combine-architect, скелет combine-skeleton. Если субагенты combine-* в этой среде недоступны, прямо запиши это в docs/REPORT-1.md, раздел 4, и выполни работу сам, соблюдая разделение ролей по возможности.
4. Перед выводами про любой аналог или библиотеку открывай актуальную официальную документацию и версию (CORE п.3). Если веб недоступен, запиши это в отчёт и не выдумывай данные.
5. Работай в ветке claude/stage-0-skeleton, коммить небольшими шагами. В main не пушить, force-push не делать.
6. После этапа 5 остановись. В конце ответа дай короткий итог (до 15 строк): что сделано, чем проверено, что нет, вопросы владельцу, ссылка на docs/REPORT-1.md.
```

Основная сессия лучше на Sonnet (оркестрация), сильные модели подключаются через агентов `combine-*`.
