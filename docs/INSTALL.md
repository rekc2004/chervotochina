# Установка и первая проверка

Документ для пользователя. Пометки «не проверено» означают, что описание взято из документации ОС или памяти и на нашей машине не прогонялось (дата: 2026-10-28).

## 1. Какой файл скачать

Релизы лежат на странице GitHub Releases проекта. Первые публичные релизы выпускаются владельцем вручную: черновик публикуется после его проверки.

Рекомендуется установщик для вашей ОС: он ставит программу в нужное место, добавляет её в меню, значок и список установленных программ, а удаляется штатно. Одиночный файл тоже годится: переносной запуск, ручное обновление «заменить файл», машины без `apt`.

| ОС | Установщик (рекомендуется) | Одиночный файл |
|---|---|---|
| Windows | `chervotochina-<версия>-windows-x86_64-setup.exe` | `chervotochina-<версия>-windows-x86_64.exe` |
| macOS, Apple Silicon | `chervotochina-<версия>-macos-aarch64.dmg` | `chervotochina-<версия>-macos-aarch64.zip` |
| macOS, Intel | `chervotochina-<версия>-macos-x86_64.dmg` | `chervotochina-<версия>-macos-x86_64.zip` |
| Linux (Ubuntu, Debian) | `chervotochina-<версия>-linux-x86_64.deb` | `chervotochina-<версия>-linux-x86_64` |

Установщик кладёт тот же файл, который лежит в выпуске отдельно и подписан владельцем (CI это проверяет: после тихой установки хэш установленного файла равен строке манифеста одиночного файла). Установщик Windows собран программой Inno Setup 6.7.4 (авторы Jordan Russell и Martijn Laan, <https://jrsoftware.org/isinfo.php>). На Linux в пакет входит и консольная `chervo`.

На Linux без `.deb` есть консольная программа `chervo-<версия>-linux-x86_64`: для машины без рабочего стола и для проверок из терминала (`chervo doctor`, `chervo verify-release`). На Windows и macOS консольной программы в выпуске нет.

Тексты лицензий сторонних библиотек: `chervo-<версия>-third-party-licenses.txt`.

Состояние проверки: установщики проверены только в CI (тихая установка, сверка хэша, запуск, удаление). На настоящих машинах они не проверены: список в `scripts/release/sign.sh`, чек-лист владельца. Если что-то отличается от описанного ниже, не продолжайте и пришлите журнал.

Кроме программы скачайте `chervo-release.txt` (манифест) и `chervo-release.txt.minisig` (подпись манифеста). Подписи самих файлов лежат рядом (`<файл>.minisig`).

## 2. Проверка первой загрузки

Программа ещё не стоит у вас, поэтому проверять приходится внешним `minisign` (на всех ОС одинаково):

    minisign -Vm chervo-release.txt -P <публичный ключ владельца из README>

Публичный ключ и его `key_id` сверяйте по второму каналу (README репозитория и сообщение владельца), а не только со страницы релиза. Подпись должна пройти. Затем сверьте SHA-256 скачанного файла со строкой манифеста (строка `artifact <цель> <SHA-256> <размер> <имя>`):

- Linux: `sha256sum <файл>`;
- macOS: `shasum -a 256 <файл>` (для `.zip` до распаковки);
- Windows (PowerShell): `Get-FileHash -Algorithm SHA256 <файл>` (не проверено).

Следующие версии проверяются уже самой программой, офлайн: на экране «Обновления» окна выберите скачанные манифест, подпись и файл. На Linux то же делает `chervo verify-release chervo-release.txt chervo-release.txt.minisig <файл>`: печатает `OK` или `FAIL <код>` по каждому файлу, код возврата 0 только если прошли все.

Проверку делайте для установщика **до** его запуска. Запускайте скачанный файл из чистой папки, в которой нет посторонних файлов и библиотек (рядом лежащая подложенная DLL может быть загружена установщиком).

## 3. Windows

Установщик `chervotochina-<версия>-windows-x86_64-setup.exe` ставит программу только для вас (текущего пользователя), без прав администратора, в `%LOCALAPPDATA%\Programs\Chervotochina`. Папку выбрать нельзя. Не проверено на настоящей Windows 11.

1. Проверьте файл по разд. 2.
2. Файл не подписан сертификатом Microsoft, SmartScreen может предупредить. Нажмите «Подробнее», затем «Выполнить в любом случае». Делайте это только после проверки из разд. 2.
3. Окно запроса прав администратора (UAC) появляться не должно. Если оно появилось, не продолжайте: прервите установку и пришлите журнал (команда ниже).
4. Программа появится в меню «Пуск» («Червоточина») и в «Параметры -> Приложения».
5. Брандмауэр Windows при первом запуске спросит разрешение: путь программы новый, прежние разрешения к нему не относятся (так должно быть, не проверено).

Журнал установки: запустите установщик командой `chervotochina-<версия>-windows-x86_64-setup.exe /LOG="%USERPROFILE%\Desktop\chervo-setup.log"`. Штатный журнал Inno Setup также лежит в `%TEMP%\Setup Log *.txt` (не проверено).

Одиночный файл `chervotochina-*.exe` запускается как есть, без установки, Microsoft Visual C++ не нужен (не проверено на чистой Windows 11).

Окно и панель задач показывают значок программы. В «Проводнике» у самого `.exe` значок стандартный: это ограничение выбранного способа (значок не вшит в файл, чтобы файл установщика и одиночный файл совпадали побайтно).

## 4. macOS: Gatekeeper

Приложение не подписано Apple (подпись ad-hoc, без нотаризации); образ `.dmg` тоже не подписан. Порядок:

1. Проверьте `.dmg` (или `.zip`) по разд. 2 до открытия.
2. Откройте `.dmg`: в окне будут `Chervotochina.app` и ссылка «Applications». Перенесите `Chervotochina.app` мышью на «Applications» («Программы»). Тот же `Chervotochina.app` лежит и в `.zip`.
3. Первый запуск: «Системные настройки -> Конфиденциальность и безопасность -> Всё равно открыть» (пункт появляется после первой попытки запуска). Поведение macOS 15 не проверено.
4. Запасной путь, если пункта нет: в терминале `xattr -dr com.apple.quarantine /Applications/Chervotochina.app`.

Удаление: перенесите `Chervotochina.app` из «Программ» в Корзину. Данные остаются (разд. 9).

На macOS программа не проверялась на реальной машине; в CI проверено: состав образа, побайтное совпадение `.app` с `.zip`, подпись ad-hoc, запуск копии.

## 5. Linux

Пакет `.deb` (Ubuntu, Debian), после проверки по разд. 2:

    sudo apt install ./chervotochina-<версия>-linux-x86_64.deb

`apt` ничего, кроме самого пакета, не ставит: пакет требует только `libc6` (и `libgcc-s1`), хранилище ключей лишь предлагается (`Suggests: gnome-keyring`: `apt` покажет его в строке «Предлагаемые пакеты» и не поставит). Скриптов установки в пакете нет, от имени root только копируются файлы. В пакете оба файла: `/usr/bin/chervotochina` (окно, значок в списке программ) и `/usr/bin/chervo` (консоль). Удаление:

    sudo apt remove chervotochina

Данные остаются (разд. 9). Не проверено на настоящей машине (в CI пакет ставится и удаляется на Ubuntu 22.04 и 24.04).

Одиночный файл без установки:

    chmod +x chervotochina-<версия>-linux-x86_64
    ./chervotochina-<версия>-linux-x86_64

Нужен графический сеанс X11 или Wayland. Ключи хранятся в хранилище ОС через Secret Service (D-Bus). Его дают gnome-keyring, KWallet с включённым Secret Service, KeePassXC (интеграция Secret Service). Не проверено на всех трёх. Если хранилища нет, первый экран окна скажет об этом, а `chervo doctor` даст подробности. На машине без рабочего стола см. `docs/HEADLESS_LINUX.md`.

## 6. `chervo doctor` (только Linux)

Проверяет хранилище ключей ОС, только чтение: ничего не пишет, пароль не запрашивает, программ не запускает. Печатает одну строку:

- `хранилище ключей доступно` (код 0);
- `хранилище заблокировано: разблокируйте ...` (код 1): разблокируйте связку ключей средствами ОС;
- `хранилище ключей недоступно: ...` (код 1): в строке указано, что установить;
- лишние аргументы: код 2.

На Windows и macOS консольной программы нет: состояние хранилища показывает первый экран окна.

## 7. Обновление вручную

Программа сама не обновляется: замена исполняемого файла без вашего ведома была бы каналом доставки вредоносного кода при взломе сайта. Порядок: скачайте новый файл, манифест и подпись; проверьте файл на экране «Обновления» (установщик, как и одиночный файл, проверяется по хэшу; на Linux ещё и `chervo verify-release`); закройте программу; затем:

- Windows: запустите новый установщик поверх старого (прежняя установка обновится; ключи и книга друзей не затрагиваются) или замените одиночный `.exe`;
- macOS: замените `Chervotochina.app` из нового `.dmg` (или `.zip`);
- Linux: `sudo apt install ./chervotochina-<новая версия>-linux-x86_64.deb` или замените одиночный файл.

Установщик не мешает поставить и более старую версию поверх новой: это ваше действие, экран «Обновления» предупреждает об откате.

## 8. Уведомление о новой версии

Поведение окна ниже описано по спецификации 19г (реализация окна: подэтап 19г-2); до приёмки выпуска это не проверено.

При первом запуске окно спрашивает, включить ли проверку новых версий. До вашего ответа проверки нет, ответ можно изменить в настройках.

Что уходит в сеть при включённой проверке: один запрос к GitHub за номером последней версии, не чаще раза в сутки в фоне и по кнопке «Проверить сейчас» (не чаще раза в минуту). GitHub видит ваш IP-адрес и время запроса. Ничего из ваших данных программа не отправляет. Программа показывает только номер версии и адрес страницы выпусков (его можно скопировать кнопкой «Копировать»), сама ничего не скачивает и браузер не открывает.

Как выключить: переключатель в настройках (или ответ «нет» на карточке при первом запуске). На Linux есть и консольная команда `chervo check-update`.

## 9. Удаление и данные пользователя

Ни один установщик при удалении не трогает ваши данные и записи в хранилищах ключей ОС (Credential Manager, связка ключей macOS, Secret Service). Данные лежат в другом месте, чем сама программа:

- Windows: `%LOCALAPPDATA%\Chervotochina` (это не папка установки `%LOCALAPPDATA%\Programs\Chervotochina`);
- macOS: `~/Library/Application Support/Chervotochina`;
- Linux: `$XDG_DATA_HOME/chervotochina` или `~/.local/share/chervotochina`.

Удалить данные можно только вручную: удалите эту папку и записи «Червоточины» в хранилище ключей. Предупреждение: вместе с ключами пропадают ваши пары, и всех друзей придётся добавлять заново (приглашение и сверка кода на обоих экранах). Если вы только переустанавливаете программу, ничего удалять не нужно.
