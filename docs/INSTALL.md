# Установка и первая проверка

Документ для пользователя. Пометки «не проверено» означают, что описание взято из документации ОС или памяти и на нашей машине не прогонялось (дата: 2026-10-27).

## 1. Где скачать

Релизы лежат на странице GitHub Releases проекта. Для вашей ОС нужен один файл `chervo-<версия>-<ОС>-<архитектура>` (на Windows с `.exe`), а также `chervo-release.txt` (манифест) и `chervo-release.txt.minisig` (подпись). Первые публичные релизы выпускаются владельцем вручную: черновик публикуется после его проверки.

## 2. Проверка первой загрузки

Программа ещё не стоит у вас, поэтому проверять приходится внешним `minisign`:

    minisign -Vm chervo-release.txt -P <публичный ключ владельца из README>

Публичный ключ и его `key_id` сверяйте по второму каналу (README репозитория и сообщение владельца), а не только со страницы релиза. Подпись должна пройти, затем сверьте SHA-256 скачанного файла со строкой манифеста.

После запуска программа проверяет релизы сама, офлайн:

    chervo release-keys
    chervo verify-release chervo-release.txt chervo-release.txt.minisig <файл>

`verify-release` печатает `OK` или `FAIL <код>` по каждому файлу. Код возврата 0 только если прошли все.

## 3. Windows: SmartScreen

Файл не подписан сертификатом Microsoft, SmartScreen может предупредить. Нажмите «Подробнее», затем «Выполнить в любом случае». Делайте это только после проверки из разд. 2. Не проверено.

## 4. macOS: Gatekeeper

Программа не подписана Apple. Запуск: «Системные настройки -> Конфиденциальность и безопасность -> Всё равно открыть» (появляется после первой попытки запуска) либо в терминале `xattr -d com.apple.quarantine <файл>`. Поведение macOS 15 не проверено.

## 5. Linux

    chmod +x chervo-<версия>-linux-x86_64
    ./chervo-<версия>-linux-x86_64 doctor

Ключи хранятся в хранилище ОС через Secret Service (D-Bus). Его дают gnome-keyring, KWallet с включённым Secret Service, KeePassXC (интеграция Secret Service). Не проверено на всех трёх. На машине без рабочего стола см. `docs/HEADLESS_LINUX.md`.

## 6. `chervo doctor`

Проверяет хранилище ключей ОС, только чтение: ничего не пишет, пароль не запрашивает, программ не запускает. Печатает одну строку:

- `хранилище ключей доступно` (код 0);
- `хранилище заблокировано: разблокируйте ...` (код 1): разблокируйте связку ключей средствами ОС;
- `хранилище ключей недоступно: ...` (код 1): в строке указано, что установить;
- лишние аргументы: код 2.

## 7. Обновление вручную

Программа сама не обновляется: замена исполняемого файла без вашего ведома была бы каналом доставки вредоносного кода при взломе сайта. Порядок: скачайте новый файл, манифест и подпись, выполните `chervo verify-release`, затем замените файл сами.
