# Установка и первая проверка

Документ для пользователя. Пометки «не проверено» означают, что описание взято из документации ОС или памяти и на нашей машине не прогонялось (дата: 2026-10-28).

## 1. Какой файл скачать

Релизы лежат на странице GitHub Releases проекта. Первые публичные релизы выпускаются владельцем вручную: черновик публикуется после его проверки.

Нужен файл программы с окном `chervotochina` для вашей ОС:

- Windows: `chervotochina-<версия>-windows-x86_64.exe`;
- macOS: `chervotochina-<версия>-macos-aarch64.zip` (Apple Silicon) или `chervotochina-<версия>-macos-x86_64.zip` (Intel);
- Linux: `chervotochina-<версия>-linux-x86_64`.

На Linux дополнительно есть консольная программа `chervo-<версия>-linux-x86_64`: для машины без рабочего стола и для проверок из терминала (`chervo doctor`, `chervo verify-release`). На Windows и macOS консольной программы в выпуске нет.

Тексты лицензий сторонних библиотек: `chervo-<версия>-third-party-licenses.txt`.

Кроме программы скачайте `chervo-release.txt` (манифест) и `chervo-release.txt.minisig` (подпись манифеста). Подписи самих файлов лежат рядом (`<файл>.minisig`).

## 2. Проверка первой загрузки

Программа ещё не стоит у вас, поэтому проверять приходится внешним `minisign` (на всех ОС одинаково):

    minisign -Vm chervo-release.txt -P <публичный ключ владельца из README>

Публичный ключ и его `key_id` сверяйте по второму каналу (README репозитория и сообщение владельца), а не только со страницы релиза. Подпись должна пройти. Затем сверьте SHA-256 скачанного файла со строкой манифеста (строка `artifact <цель> <SHA-256> <размер> <имя>`):

- Linux: `sha256sum <файл>`;
- macOS: `shasum -a 256 <файл>` (для `.zip` до распаковки);
- Windows (PowerShell): `Get-FileHash -Algorithm SHA256 <файл>` (не проверено).

Следующие версии проверяются уже самой программой, офлайн: на экране «Обновления» окна выберите скачанные манифест, подпись и файл. На Linux то же делает `chervo verify-release chervo-release.txt chervo-release.txt.minisig <файл>`: печатает `OK` или `FAIL <код>` по каждому файлу, код возврата 0 только если прошли все.

## 3. Windows: SmartScreen

Файл не подписан сертификатом Microsoft, SmartScreen может предупредить. Нажмите «Подробнее», затем «Выполнить в любом случае». Делайте это только после проверки из разд. 2. Установщика нет: `chervotochina-*.exe` запускается как есть, Microsoft Visual C++ не нужен (не проверено на чистой Windows 11). Не проверено.

## 4. macOS: Gatekeeper

Приложение не подписано Apple (подпись ad-hoc, без нотаризации). Порядок:

1. Проверьте `.zip` по разд. 2 до распаковки.
2. Распакуйте архив и перенесите `Chervotochina.app` в «Программы».
3. Первый запуск: «Системные настройки -> Конфиденциальность и безопасность -> Всё равно открыть» (пункт появляется после первой попытки запуска). Поведение macOS 15 не проверено.
4. Запасной путь, если пункта нет: в терминале `xattr -dr com.apple.quarantine /Applications/Chervotochina.app`.

На macOS программа не проверялась на реальной машине.

## 5. Linux

    chmod +x chervotochina-<версия>-linux-x86_64
    ./chervotochina-<версия>-linux-x86_64

Нужен графический сеанс X11 или Wayland. Ключи хранятся в хранилище ОС через Secret Service (D-Bus). Его дают gnome-keyring, KWallet с включённым Secret Service, KeePassXC (интеграция Secret Service). Не проверено на всех трёх. Если хранилища нет, первый экран окна скажет об этом, а `chervo doctor` даст подробности. На машине без рабочего стола см. `docs/HEADLESS_LINUX.md`.

## 6. `chervo doctor` (только Linux)

Проверяет хранилище ключей ОС, только чтение: ничего не пишет, пароль не запрашивает, программ не запускает. Печатает одну строку:

- `хранилище ключей доступно` (код 0);
- `хранилище заблокировано: разблокируйте ...` (код 1): разблокируйте связку ключей средствами ОС;
- `хранилище ключей недоступно: ...` (код 1): в строке указано, что установить;
- лишние аргументы: код 2.

На Windows и macOS консольной программы нет: состояние хранилища показывает первый экран окна.

## 7. Обновление вручную

Программа сама не обновляется: замена исполняемого файла без вашего ведома была бы каналом доставки вредоносного кода при взломе сайта. Порядок: скачайте новый файл, манифест и подпись; проверьте файл на экране «Обновления» (на Linux ещё и `chervo verify-release`); закройте программу; замените файл сами (на macOS замените `Chervotochina.app`).

## 8. Уведомление о новой версии

Поведение окна ниже описано по спецификации 19г (реализация окна: подэтап 19г-2); до приёмки выпуска это не проверено.

При первом запуске окно спрашивает, включить ли проверку новых версий. До вашего ответа проверки нет, ответ можно изменить в настройках.

Что уходит в сеть при включённой проверке: один запрос к GitHub за номером последней версии, не чаще раза в сутки в фоне и по кнопке «Проверить сейчас» (не чаще раза в минуту). GitHub видит ваш IP-адрес и время запроса. Ничего из ваших данных программа не отправляет. Программа показывает только номер версии и адрес страницы выпусков (его можно скопировать кнопкой «Копировать»), сама ничего не скачивает и браузер не открывает.

Как выключить: переключатель в настройках (или ответ «нет» на карточке при первом запуске). На Linux есть и консольная команда `chervo check-update`.
