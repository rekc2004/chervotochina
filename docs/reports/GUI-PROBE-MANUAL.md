# Ручная проверка пробы GUI (этап 18p)

Проба — маленькая программа на egui. Она ничего не передаёт и не сохраняет: окно с надписями, полем ввода, кнопками, кодом SAS `1234 5678`, QR-кодом, выбором файла и папки. Вверху окна строка «Адаптер: ...» показывает, чем рисуется окно (видеокарта или программная отрисовка). Результаты записывайте в таблицу в конце: «да / нет / что видно».

## Где взять сборки
GitHub → репозиторий → Actions → workflow **gui-probe** → последний зелёный запуск на ветке `claude/angry-ritchie-a296d8` → раздел Artifacts:
- `gui-probe-Windows-<sha>` → `gui-probe.exe`;
- `gui-probe-Linux-<sha>` → `gui-probe` (после распаковки: `chmod +x gui-probe`);
- `gui-probe-macOS-<sha>` → `gui-probe` (не подписан: правый клик → «Открыть», либо `xattr -d com.apple.quarantine gui-probe`).

Сборки хранятся 30 дней. Ничего, кроме самого файла, ставить не нужно — это и проверяем.

## Машины
1. **Чистая Windows 11** в виртуальной машине (Hyper-V или VirtualBox) без драйвера видеокарты и без доустановленных пакетов (Visual C++ Redistributable в том числе).
2. **Чистая Ubuntu 24.04 Desktop** в виртуальной машине без 3D-ускорения (программная отрисовка llvmpipe). Проверить дважды: в сеансе Wayland (по умолчанию) и в сеансе «Ubuntu on Xorg» (выбор на экране входа, шестерёнка).
3. **Ваш рабочий Windows-ПК** (для диктора и раскладок).
4. **macOS**, если есть доступ.
5. Старая видеокарта — если есть такая машина.

## Что проверить на каждой машине
- **V3/V4 запуск.** Двойной щелчок по файлу (на Linux — `./gui-probe` из терминала). Открылось ли окно без сообщений о недостающих DLL/библиотеках? Что написано в строке «Адаптер»? Если окно не открылось: запустите с переменной `GUI_PROBE_RENDERER=glow` (Windows PowerShell: `$env:GUI_PROBE_RENDERER="glow"; .\gui-probe.exe`; Linux: `GUI_PROBE_RENDERER=glow ./gui-probe`) и запишите, помогло ли.
- **Быстрая проверка без окна:** `gui-probe --render-check` должна завершиться сама за несколько секунд; код выхода 0 (PowerShell: `$LASTEXITCODE`, Linux: `echo $?`).
- **V5 русский ввод.** В поле ввода напечатайте по-русски, переключая раскладку. В русской раскладке: Ctrl+A, Ctrl+C, Ctrl+V, Ctrl+X — работают? Буквы отображаются (нет квадратиков)? Скопируйте длинный текст из Блокнота и вставьте в поле — вставился целиком?
- **V5 IME (по желанию).** Включите японскую или китайскую раскладку Windows, наберите слово, подтвердите — текст появился в поле?
- **V6 диктор.** Windows: Win+Ctrl+Enter (Narrator). macOS: Cmd+F5 (VoiceOver). Клавишей Tab пройдите по всем элементам: диктор называет кнопки? Код SAS читается как «1 2 3 4 5 6 7 8»? Shift+Tab, Enter и Пробел работают? На Linux диктора нет по вашему решению — только Tab/Enter.
- **V7 файлы.** Кнопки «Выбрать файл» и «Выбрать папку»: открывается системный диалог (на Linux — какой: GNOME или иной)? После выбора путь виден в окне? Перетащите файл из проводника/Files в окно — путь появился? На Linux отметьте отдельно для Wayland и Xorg.
- **V2 сеть (Linux, по желанию).** Пока окно открыто, в терминале: `ss -uptn | grep gui-probe` — пусто?
