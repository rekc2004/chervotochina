## Proposal for the project deny.toml (18b), as verified in the probe copy
```toml
[graph]
exclude = ["accesskit_unix"]   # optional Linux-only dep of accesskit_winit; not built for any target

[[licenses.exceptions]]
name = "epaint_default_fonts"
allow = ["OFL-1.1", "Ubuntu-font-1.0"]
[[licenses.exceptions]]
name = "clipboard-win"
allow = ["BSL-1.0"]
[[licenses.exceptions]]
name = "error-code"
allow = ["BSL-1.0"]
```
Why `[graph] exclude` is sound: cargo-deny works from cargo metadata and does not apply per-target feature resolution, so it sees accesskit_unix (default feature of accesskit_winit, enabled by egui-winit). The crate is compiled for no target, because eframe `accesskit` is off on Linux and the dep is unix-only. `check-linux-tree.sh` fails CI if zbus/zvariant/zbus_names/accesskit_unix reach the Linux tree. Bans on zvariant & co unchanged; no advisory ignores.
