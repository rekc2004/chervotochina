# Эхо-сервер `chervo-rendezvous`

Маленькая программа для компьютера, который всегда доступен из интернета (ваш или знакомого).
Она отвечает на один вопрос: «с какого адреса и порта меня видно». Червоточина вписывает ответ в
приглашение. Устройство и угрозы: `docs/specs/stage-13d-echo.md`. Сервер ничего не пишет на диск,
не печатает адреса клиентов и не хранит их дольше окна лимита, секретов у него нет. Клиент вписывает
адрес сервера на вкладке «Настройки», раздел «Связь через интернет».

## Сборка
    cargo build --release --locked -p chervo-rendezvous-server
Файл: `target/release/chervo-rendezvous` (в выпуск Червоточины не входит).

## Запуск
    chervo-rendezvous --listen 203.0.113.5:45900 --reach-port 45901
- `--listen IP:PORT`: основной порт, можно повторить для IPv6 (`[2001:db8::5]:45900`). Указывайте
  конкретный IP компьютера, не `0.0.0.0`: ответ должен уходить с того же адреса.
- `--reach-port N`: второй порт на том же IP, для кнопки «Проверить» помощника доступа. Без него
  проверка недоступна, эхо работает.
- `--allow-private`: отвечать и частным адресам (дома, для тестов). По умолчанию только публичным.
- `--report-secs N`: как часто печатать счётчики, 60..86400, по умолчанию 600.
- Портов по умолчанию нет, числа выше только пример. Код выхода 2: неверные аргументы, 1: не удалось
  занять адрес или порт.
- Лимиты: 16 ответов за 10 с на адрес (IPv6 по сети /64) и 1000 ответов в секунду.

## Брандмауэр
Откройте UDP для обоих портов. Если у машины «серый» внутренний адрес (облако, 1:1 NAT), слушайте
внутренний адрес и пробросьте оба порта на него.

## systemd (`/etc/systemd/system/chervo-rendezvous.service`)
    [Unit]
    After=network-online.target
    [Service]
    ExecStart=/usr/local/bin/chervo-rendezvous --listen 203.0.113.5:45900 --reach-port 45901
    DynamicUser=yes
    Restart=on-failure
    NoNewPrivileges=yes
    [Install]
    WantedBy=multi-user.target
`journalctl -u chervo-rendezvous` покажет только строку старта и счётчики, без адресов клиентов.
