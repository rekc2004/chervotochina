# Червоточина

Прямая передача файлов между компьютерами без облака и посредников, в российском сегменте интернета без VPN. Личный проект.

Статус: подготовка. Постановка: [docs/BRIEF.md](docs/BRIEF.md). Рабочий статус: [docs/TASK.md](docs/TASK.md). Работа ведётся по правилам [Комбайна](https://github.com/rekc2004/combine) (файлы `.claude/combine`, `.claude/agents`).
