# Быстрое ревью

Прогони свой diff по чек-листу, ничего не придумывая сверх него:

1. Делает ли код то, что просили, и только это? Нет ли лишних изменений.
2. Обрабатывается ли недоверенный ввод (файлы, сеть, пути, имена) как враждебный.
3. Нет ли секретов, ключей и личных данных в коде и в логах.
4. Есть ли тест или проверка на новое поведение и на ошибочный случай.
5. Не сломан ли публичный интерфейс.

Результат: список найденного с указанием файла и строки, либо «замечаний нет». Для глубокого ревью безопасности используй агента `combine-security`, а не этот скилл.

Место для тяжёлого ревьюера: добавьте его отдельным скиллом `review.deep` с `"cost": "дорого"` и `"default": false`, тогда он ставится только по `--with review.deep`.
